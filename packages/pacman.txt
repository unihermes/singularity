# GTK3 looks for an actual theme folder named "Adwaita-dark", it does not
# derive one from gtk-application-prefer-dark-theme the way libadwaita (GTK4)
# apps do. Without this package the name in settings.ini/gsettings resolves
# to nothing and GTK3 apps -- Thunar included -- silently fall back to light
# Adwaita no matter what those files say.

# ones, so the shell's generated gtk3.css recolours them like GTK4 apps.

# images + video
# Same reasoning as zathura, and the same shape: imv and mpv are both
# keyboard-driven, both Wayland-native, and neither drags in a toolkit the
# rest of the desktop doesn't already use. VLC would work and is a one-line
# swap, but it brings its own Qt UI and its own idea of theming.
#
# These are also what stops the PDF viewer answering for images: zathura's
# mupdf plugin claims image/png, image/jpeg, image/bmp, image/svg+xml and
# image/tiff in its .desktop, so with nothing else installed it wins every
# image by default. install.sh hands those to imv explicitly.
imv
mpv
