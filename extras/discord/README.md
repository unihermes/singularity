# Discord (Equicord) CSS

Kept for reference; nothing installs these. The Singularity theme itself is
written by the shell (`services/AppearanceSync.qml`, `renderDiscord`), so it
isn't here.

- `quickCss.css`: Equicord's QuickCSS (Settings > Equicord > QuickCSS), in
  `~/.config/Equicord/settings/`. Ubuntu Nerd Font everywhere, and a zoom so
  Discord is the same physical size on a 1440p and a 1080p monitor; that part
  assumes `--force-device-scale-factor=0.67` and those two widths.
- `UIRefreshRefresh.theme.css`: the UI Refresh Refresh theme (programmer2514),
  enabled next to Singularity; goes in `~/.config/Equicord/themes/`.

Restore: copy each file to its folder, then enable the theme under Themes.
